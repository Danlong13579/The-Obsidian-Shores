# The Obsidian Shores

An interactive story game with a card battle system featuring deep branching narratives and strategic combat that can be bypassed through unique dialogue choices.

## Features

- **Deep Branching Narratives** - Multiple story paths shaped by your decisions
- **Strategic Card-Based Combat** - Engaging tactical battles with meaningful mechanics
- **Unique Dialogue System** - Avoid combat entirely through clever conversation choices
- **Multiple Protagonists** - Intertwined character arcs that influence the story

## Project Structure

- `Assets/DialogTrees/` - Dialogue and narrative branching systems
- `Assets/Scripts/` - Core game logic and systems
- `Assets/Scenes/` - Game levels and scenes
- `Assets/Samples/` - Example implementations and tutorials
- `ProjectSettings/` - Unity project configuration

## Getting Started

### Prerequisites

- Unity 6.4 Latest (plans for 6.5)
- Visual Studio or preferred C# IDE

### Installation

1. Clone the repository
2. Open the project in Unity (ensure you have the required packages installed)
3. Open the main scene from `Assets/Scenes/`
4. Press Play to run the game

### Input System

The project uses Unity's new Input System. Input actions are configured in `Assets/InputSystem_Actions.inputactions`.

## Development

- Built with Unity's Graph Toolkit and Visual Novel Director
- Uses TextMesh Pro for UI text rendering
- Modular script structure for easy extension
